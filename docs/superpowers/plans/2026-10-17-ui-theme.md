# Dishkept Look and Feel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the web app the owner's Dishkept theme, with a shared dark theme, about ten building blocks and a bottom tab bar, and rename it Dishkept with the new icon, without changing what any screen does.

**Architecture:**
- `src/theme` holds the tokens (colors, type, spacing).
- `src/ui` holds the building blocks; screens use only these and never write colors.
- A `TabBar` rendered by the root layout replaces the list screen's links. Favorites becomes its own route, and the search filter is shared between Recipes and Favorites through a tiny store.
- Icons are generated from the owner's artwork by a Chromium script, as `photos:samples` already does.

**Tech Stack:**
- Expo 57 and React Native Web 0.21, with Expo Router;
- `expo-font`, `@expo/vector-icons` (an Ionicons subset), `@expo-google-fonts/outfit` and `@expo-google-fonts/plus-jakarta-sans`;
- Playwright (Chromium) for the icon script and e2e;
- Vitest.

**Spec:** `docs/superpowers/specs/2026-10-17-ui-theme-design.md`

## Global Constraints

- **Colors**, exactly: `bg #0E121A`, `surface #1A1F2C`, `raised #242A3A`, `line #2A3142`, `accent #00F5D4`, `tag #FF9F1C`, `text #F8F9FA`, `muted #9AA3B5`, `danger #FF6B6B`, `onAccent #0E121A`.
- **Contrast:** every text and background pair meets WCAG AA (4.5:1). Mint and amber backgrounds carry `onAccent` text, never white.
- **Fonts:** headings in Outfit (600), body in Plus Jakarta Sans (400/500/700), bundled with the app. Nothing is loaded from Google, and the app never waits for fonts.
- **Sizes:** `h1` 28, `h2` 20, `h3` 17, `body` 16, `small` 14, `caption` 12. Spacing `xs` 4, `sm` 8, `md` 12, `lg` 16, `xl` 24. Radii `card` 16, `field` 12, `pill` 999. Every tap target is at least 44 × 44.
- **No color literals** (`#…`, `rgb(…)`, `rgba(…)`) in `apps/mobile/src` or `apps/mobile/app` outside `src/theme/` and tests.
- **Name:** the app is called "Dishkept", with the tagline "Keep Your Kitchen Inspired". The list heading stays "Recipes".
- **Tab bar:**
  - items: Recipes (`/`) · Favorites (`/favorites`) · raised **+** ("Add a recipe", or "Add a recipe, N imports ready") · Household (`/household`);
  - the **+** is hidden for Viewers;
  - the whole bar is hidden in cook mode, the photo viewer, sign-in, the invite page and `/s/<code>`, and whenever signed out.
- **Addresses:** every existing address stays; `/favorites` is the only new one.
- **Behavior:** offline rules, role checks and data are unchanged. Accessible names of controls stay as they are, except where navigation moves (spec §8).
- **Bundle:** the entry bundle grows by at most 40 KB.

## Review Focus

1. **A long recipe title or a long tag on a narrow phone** (390 px, a 120-character title). The cook expects the title to wrap to two lines, the chip to shorten, and the star to stay on screen. Pinned in Task 4 (`look.spec.ts`).
2. **The last recipe on the list with the tab bar and the iPhone home indicator.** The cook expects to scroll it fully clear of the tab bar. Pinned in Task 4 (`look.spec.ts`).
3. **The fonts fail to load** (a first offline start, or a blocked file). The cook expects readable system text, not Times New Roman or blank text. Pinned in Task 7 (`look.spec.ts`).
4. **Escape or a tap outside the "+" sheet.** The cook expects it to close; a Viewer never sees "+". Pinned in Task 4 (`navigation.spec.ts`).
5. **A recipe with no photo, or one not on this device yet.** The cook expects a quiet placeholder with the app mark, never a broken image, and screen readers hear nothing extra. Pinned in Task 4 (`look.spec.ts`).

## Decisions made while planning (deviations the spec allows or forces)

- **`RowCard`, not `ListRow`:** `src/recipes/rows.ts` already exports a type called `ListRow`, so the building block is named `RowCard`.
- **One summary line on the recipe page:** it stays as one "Serves 4 · Prep 15 min · Cook 40 min" line with a clock icon instead of three chips. `recipes.spec.ts:32` asserts that exact text, and the line reads the same.
- **The search filter is shared** between Recipes and Favorites (`src/recipes/listFilter.ts`). That keeps today's behavior, which `search.spec.ts` relies on: switching tabs keeps the query and tags. A side effect: the filter also survives opening a recipe and coming back, and it is cleared on sign out.
- **`Thumb` lives in `src/components`,** not `src/ui`: it shows a `PhotoImage`, and that component uses `src/ui`, so keeping it in `src/ui` would make an import cycle.
- **The placeholder thumb is decorative** (`aria-hidden`), so no image announces "Photo of …" for a recipe without one.
- **Icon fill:** the icon's corners are filled with the icon's own navy, `#101B31`, not `bg`, so the edge blends.

`scripts/make-icons.mjs`:

```js
// Makes the app icons from the owner's artwork (UI spec §6). Run by hand when
// the artwork changes: `pnpm icons:make`. The outputs are committed.
// app_icon.png is a crop of the theme board: the navy rounded square sits
// inside it, with some of the board's background around it.
import { mkdirSync, readFileSync, writeFileSync } from 'node:fs';
import { dirname } from 'node:path';
import { chromium } from '@playwright/test';

const SOURCE = 'apps/mobile/assets/ui/app_icon.png';
// The rounded square inside the source, in source pixels.
const CROP = { x: 56, y: 49, size: 288 };
// Corner radius of the rounded square, as a share of its side.
const RADIUS = 0.2;
// The icon's own navy, so filled corners blend with it.
const NAVY = '#101B31';
const OUTPUTS = [
  { file: 'apps/mobile/assets/icon.png', size: 1024, kind: 'square' },
  { file: 'apps/mobile/public/icons/apple-touch-icon.png', size: 180, kind: 'square' },
  { file: 'apps/mobile/public/icons/icon-192.png', size: 192, kind: 'square' },
  { file: 'apps/mobile/public/icons/icon-512.png', size: 512, kind: 'square' },
  // Android crops maskable icons to a circle: keep the art in the middle 80%.
  { file: 'apps/mobile/public/icons/icon-maskable-512.png', size: 512, kind: 'maskable' },
  { file: 'apps/mobile/assets/favicon.png', size: 48, kind: 'rounded' },
  { file: 'apps/mobile/assets/brand/mark.png', size: 256, kind: 'rounded' },
];

const source = `data:image/png;base64,${readFileSync(SOURCE).toString('base64')}`;
const browser = await chromium.launch();
const page = await browser.newPage();

for (const output of OUTPUTS) {
  const dataUrl = await page.evaluate(
    async ({ source, crop, radius, navy, size, kind }) => {
      const image = new Image();
      image.src = source;
      await image.decode();
      const canvas = document.createElement('canvas');
      canvas.width = size;
      canvas.height = size;
      const context = canvas.getContext('2d');
      const inner = kind === 'maskable' ? size * 0.8 : size;
      const offset = (size - inner) / 2;
      // Square and maskable icons are full-bleed: the platform rounds them.
      if (kind !== 'rounded') {
        context.fillStyle = navy;
        context.fillRect(0, 0, size, size);
      }
      context.save();
      context.beginPath();
      context.roundRect(offset, offset, inner, inner, inner * radius);
      context.clip();
      context.drawImage(image, crop.x, crop.y, crop.size, crop.size, offset, offset, inner, inner);
      context.restore();
      return canvas.toDataURL('image/png');
    },
    { source, crop: CROP, radius: RADIUS, navy: NAVY, size: output.size, kind: output.kind },
  );
  mkdirSync(dirname(output.file), { recursive: true });
  writeFileSync(output.file, Buffer.from(dataUrl.split(',')[1], 'base64'));
  console.log(`wrote ${output.file} (${output.size})`);
}
await browser.close();
```

```ts
// WCAG 2 relative luminance and contrast ratio, for the theme's tests.
function channel(value: number): number {
  const s = value / 255;
  return s <= 0.03928 ? s / 12.92 : ((s + 0.055) / 1.055) ** 2.4;
}

function luminance(hex: string): number {
  const n = Number.parseInt(hex.slice(1, 7), 16);
  return (
    0.2126 * channel((n >> 16) & 255) + 0.7152 * channel((n >> 8) & 255) + 0.0722 * channel(n & 255)
  );
}

/** The contrast ratio of two `#RRGGBB` colors, from 1 to 21. */
export function contrast(a: string, b: string): number {
  const [light, dark] = [luminance(a), luminance(b)].sort((x, y) => y - x) as [number, number];
  return (light + 0.05) / (dark + 0.05);
}
```

```tsx
export function Chip({

  tone = 'neutral',
  onPress,

  'aria-pressed': ariaPressed,
```

```ts
import { useSyncExternalStore } from 'react';

// The list's search and tag filter, shared by Recipes and Favorites so that
// switching tabs keeps it, as the one list with two tabs did.
export type ListFilter = { query: string; selected: string[] };

let filter: ListFilter = { query: '', selected: [] };
const listeners = new Set<() => void>();

export function getFilter(): ListFilter {
  return filter;
}

export function setFilter(next: Partial<ListFilter>): void {
  filter = { ...filter, ...next };
  listeners.forEach((listener) => listener());
}

export function subscribeFilter(listener: () => void): () => void {
  listeners.add(listener);
  return () => listeners.delete(listener);
}

export function toggleTag(tag: string): void {
  setFilter({
    selected: filter.selected.includes(tag)
      ? filter.selected.filter((t) => t !== tag)
      : [...filter.selected, tag],
  });
}

export function clearFilter(): void {
  setFilter({ query: '', selected: [] });
}

export function useListFilter(): ListFilter {
  return useSyncExternalStore(subscribeFilter, getFilter, getFilter);
}
```

```markdown
# 17. Dishkept: a small design system of our own, dark only

Date: 2026-10-17 · Status: Accepted

## Context

The app had no shared styles: each screen wrote its own colors, and it looked like a prototype. The owner supplied a theme board (Dishkept: Dark Slate, Muted Indigo, Mint Glow, Amber, Off-White; Outfit and Plus Jakarta Sans), an icon and examples with rounded dark cards, pill tabs and a bottom tab bar.

## Decision

- **Theme tokens** in `apps/mobile/src/theme` (colors, type, spacing). Every text and background pair is tested for WCAG AA.
- **About ten building blocks** in `apps/mobile/src/ui` (Text, Button, IconButton, Card, Chip, PillTabs, TextField, RowCard, Banner, Thumb, Screen). Screens use only these.
- **A lint rule** rejects color literals outside `src/theme`, and `react-native` `Text` and `TextInput` outside `src/ui`.
- **A bottom tab bar** (Recipes, Favorites, +, Household) rendered by the root layout. Favorites is its own route, `/favorites`.
- **Fonts** (`@expo-google-fonts/outfit`, `@expo-google-fonts/plus-jakarta-sans`) and an Ionicons subset (`@expo/vector-icons`) are bundled and precached. The app never waits for them.
- **Dark only.** The app is named **Dishkept**. Icons are generated from the owner's artwork by `pnpm icons:make`.

## Alternatives considered

- **A UI kit** (React Native Paper, Tamagui, NativeWind): its own look to override, and a much bigger dependency for a web-first offline app.
- **Recoloring in place:** dark screens that still look like the prototype, and drift apart again.
- **Fonts from Google's CDN:** they break offline.

## Consequences

- New screens are built from `src/ui`. A new look means changing tokens and blocks, not screens.
- A light mode later means a second token set and a switch, with no screen changes.
- Bundled fonts and the icon font add about 0.6 MB to the precache (not the entry bundle).
```

Add to `docs/adr/README.md` after the 0016 row:

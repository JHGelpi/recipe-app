# Sharing Out Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Share any recipe as plain text, as a PDF made on the phone, or as a link that shows a snapshot to anyone and lets a signed-in admin or member save an independent copy into their own household.

**Architecture:**
- **The snapshot:** a `shares` row holds a snapshot of the recipe (and a copy of its dish photo file) taken when shared, behind a hashed link code.
- **Database functions:** `create_share`, `stop_shares`, `read_share` and `save_share` do what RLS alone can't. `read_share` is called through a new `asAnonymous` (the authenticated role with empty claims), so every policy still denies; only that function returns one snapshot.
- **On the phone:** text and PDF are built from the local recipe, with jsPDF loaded on demand.

**Tech Stack:** Postgres 17 + RLS (dbmate), PowerSync, Hono API, zod 4, jsPDF 4 (new, MIT), Expo / React Native Web, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-17-sharing-design.md`

## Global Constraints

- **Shared copies are always as written:** no scaling or conversion (spec §1).
- **Link codes:** 32 random bytes, base64url (43 characters); only the sha256 is stored. Links last until stopped. A trashed recipe's links read as unavailable until it is restored (spec §2, §4).
- **Endpoint answers:** as in spec §5's table. Unauthenticated reads send `Cache-Control: no-store`.
- **Who may act:** everyone may share; only admins and members may stop sharing or save a shared recipe (spec §2).
- **Copy, exactly** (spec §6):
  - Share menu: "Share", "Text", "PDF", "Link", "Copied", "Sharing a link needs a connection", "Share link".
  - Recipe screen: "Shared links: N · Stop sharing" (format), "Stop sharing <title>? Anyone with a link will no longer see it.".
  - Shared page: "Shared from the <household name>", "Save to my recipes", "Sign in or create an account to save <title>", "Saved to your recipes", "This recipe is already in your household", "This recipe is no longer shared", "Opening a shared recipe needs a connection".
  - Messages: "Viewers can't add recipes. Ask an admin of your household.", "Shared by the <household name>" (source line).
- **The text format:** exactly as spec §6 and the design (title, a "Serves · Prep · Cook" line, Ingredients with "• ", numbered Steps, Notes, a source line).
- **PDF:** Letter size; ingredients in two columns above 12 lines; footer "Shared from Recipes"; file name "<Title>.pdf" (spec §6).
- **App first-load size** grows by no more than 20 KB; the PDF code loads only when a PDF is made (spec §9).
- **CLAUDE.md rules 1–8.** Rule 1 gains the ADR-0016 functions and `asAnonymous`.
- **Never run `pnpm db:reset`.** Seed rows are added by hand with `on conflict do nothing`. Restart sync after changing `powersync/sync-config.yaml`.

## Review Focus

1. **A recipe with a long ingredient list and long steps** (30 ingredients, 15 paragraphs). The cook expects a PDF that flows onto more pages, never text running off the page. Pinned in Task 4 (a 3-page test).
2. **A title with characters a file name can't have** ("Mom's 1/2-batch: Pie?"). The cook expects a sensible file name, not a failed share. Pinned in Task 4 (`pdfFileName`).
3. **Ingredients with fractions the PDF's built-in font doesn't have** (⅓ ⅔ ⅛). The cook expects "1/3", never an empty box or a garbled glyph. Pinned in Task 1 (`pdfSafeText`).
4. **Saving a shared recipe whose dish photo file is missing on the server.** The cook expects the recipe saved without the photo, not a failed save. Pinned in Task 3.
5. **A share link opened by someone signed in to the household that shared it.** The cook expects "This recipe is already in your household", not a duplicate. Pinned in Task 2 (`save_share` refuses `own_household`) and Task 5.

## Decisions this plan makes inside the spec (for the executor's ledger)

- **The PDF uses jsPDF's built-in Helvetica,** with a fallback map for the few glyphs it lacks (⅓ ⅔ ⅛ ⅜ ⅝ ⅞ → 1/3 …; it keeps ½ ¼ ¾ ° • –, which WinAnsi has). The spec said "an embedded Noto Sans subset". This avoids adding a font file and keeps PDFs small.
- **The snapshot carries `photo: { bytes, width, height } | null`** instead of a separate `photo_copy` column. The saved copy's photo row needs those values.
- **Purging stopped shares uses an RLS delete policy (`shares_purge`)** plus a delete grant, instead of a `purge_shares()` definer function. The rule fits RLS like `photos_purge`, so no definer function is needed.
- **The share's household name comes from the `households` row read as the user.**

```ts
import { z } from 'zod';
import { isHttpUrl, SOURCE_LIMITS } from './imports';
import type { Ingredient } from './ingredients';
import { RECIPE_LIMITS } from './limits';
import type { Step } from './steps';
import { ingredientSchema, recipeTitleSchema, stepSchema, tagSchema } from './index';

/** FR-27, NFR-2: what a link shows; nothing else of the household. */
export const shareSnapshotSchema = z.strictObject({
  title: recipeTitleSchema,
  servings: z.number().int().min(1).max(999).nullable(),
  prep_minutes: z.number().int().min(0).max(10000).nullable(),
  cook_minutes: z.number().int().min(0).max(10000).nullable(),
  ingredients: z.array(ingredientSchema).max(RECIPE_LIMITS.ingredients),
  steps: z.array(stepSchema).max(RECIPE_LIMITS.steps),
  tags: z.array(tagSchema).max(RECIPE_LIMITS.tags),
  notes: z.string().max(RECIPE_LIMITS.notes),
  source_url: z.string().max(SOURCE_LIMITS.url).refine(isHttpUrl).nullable(),
  source_author: z.string().max(SOURCE_LIMITS.author).nullable(),
  household_name: z.string().min(1).max(200),
  shared_at: z.iso.datetime({ offset: true }),
  photo: z.strictObject({ bytes: z.number().int().positive(), width: z.number().int().positive(), height: z.number().int().positive() }).nullable(),
});
export type ShareSnapshot = z.infer<typeof shareSnapshotSchema>;

export type ShareableRecipe = {
  title: string;
  servings: number | null;
  prep_minutes: number | null;
  cook_minutes: number | null;
  ingredients: Ingredient[];
  steps: Step[];
  tags: string[];
  notes: string;
  source_url: string | null;
  source_author: string | null;
};

export const SHARE_ERRORS = ['forbidden', 'share_unavailable', 'own_household'] as const;
export type ShareError = (typeof SHARE_ERRORS)[number];

export function buildShareSnapshot(
  recipe: ShareableRecipe,
  householdName: string,
  photo: { bytes: number; width: number; height: number } | null,
  now: Date,
): ShareSnapshot {
  return {
    title: recipe.title,
    servings: recipe.servings,
    prep_minutes: recipe.prep_minutes,
    cook_minutes: recipe.cook_minutes,
    ingredients: recipe.ingredients,
    steps: recipe.steps,
    tags: recipe.tags,
    notes: recipe.notes,
    source_url: recipe.source_url,
    source_author: recipe.source_author,
    household_name: householdName,
    shared_at: now.toISOString(),
    photo,
  };
}

function host(url: string | null): string | null {
  if (!url) return null;
  try {
    return new URL(url).hostname.replace(/^www\./, '');
  } catch {
    return null;
  }
}

/** The "Serves 9 · Prep 15 min · Cook 30 min" line, or '' when there is nothing to say. */
export function timesLine(recipe: Pick<ShareableRecipe, 'servings' | 'prep_minutes' | 'cook_minutes'>): string {
  return [
    recipe.servings !== null ? `Serves ${recipe.servings}` : null,
    recipe.prep_minutes !== null ? `Prep ${recipe.prep_minutes} min` : null,
    recipe.cook_minutes !== null ? `Cook ${recipe.cook_minutes} min` : null,
  ]
    .filter(Boolean)
    .join(' · ');
}

/** "From example.com · by Jane Doe", "By Jane Doe", or ''. */
export function sourceLine(recipe: Pick<ShareableRecipe, 'source_url' | 'source_author'>): string {
  const site = host(recipe.source_url);
  if (site) return recipe.source_author ? `From ${site} · by ${recipe.source_author}` : `From ${site}`;
  return recipe.source_author ? `By ${recipe.source_author}` : '';
}

/** FR-26: the recipe as plain text, as written. */
export function shareText(recipe: Omit<ShareableRecipe, 'tags'>): string {
  const sections: string[][] = [[recipe.title, timesLine(recipe)].filter(Boolean)];
  if (recipe.ingredients.length > 0) {
    const lines = ['Ingredients'];
    for (const ingredient of recipe.ingredients) {
      if (ingredient.heading) lines.push('', ingredient.raw);
      else lines.push(`• ${ingredient.raw}`);
    }
    sections.push(lines);
  }
  if (recipe.steps.length > 0) {
    sections.push(['Steps', ...recipe.steps.map((step, index) => `${index + 1}. ${step.text}`)]);
  }
  if (recipe.notes.trim()) sections.push(['Notes', recipe.notes.trim()]);
  const source = sourceLine(recipe);
  if (source) sections.push([source]);
  return sections.map((lines) => lines.join('\n')).join('\n\n');
}

// The PDF's built-in font (WinAnsi) has ½ ¼ ¾ ° • – · but not these.
const PDF_FALLBACKS: [RegExp, string][] = [
  [/(\d)([⅓⅔⅛⅜⅝⅞])/g, '$1 $2'],
  [/⅓/g, '1/3'],
  [/⅔/g, '2/3'],
  [/⅛/g, '1/8'],
  [/⅜/g, '3/8'],
  [/⅝/g, '5/8'],
  [/⅞/g, '7/8'],
  [/≈/g, '~'],
  [/→/g, '->'],
];

/** Text the PDF's built-in font can show (Review Focus 3). */
export function pdfSafeText(text: string): string {
  return PDF_FALLBACKS.reduce((value, [pattern, replacement]) => value.replace(pattern, replacement), text);
}
```

```ts
/**
 * For signed-out visitors (ADR-0016): the authenticated role with no claims,
 * so every RLS policy denies. Only the ADR-0016 functions (read_share) may be

export function createAsAnonymous(sql: Sql) {
  const asClaims = createAsClaims(sql);
  return <T>(fn: (tx: UserTx) => Promise<T>): Promise<T> => asClaims({} as TokenClaims, fn);
}
```

```sql
-- Sharing out (FR-26, FR-27, NFR-2; ADR-0016). Runs as app_owner.
-- A share is a snapshot of a recipe behind a hashed link code. Links are read
-- without an account through read_share only; every policy still denies an
-- anonymous caller.

create table public.shares (
  id uuid primary key,
  household_id uuid not null references public.households (id),
  recipe_id uuid not null,
  token_hash bytea not null unique,
  snapshot jsonb not null check (jsonb_typeof(snapshot) = 'object'),
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  updated_by uuid references auth.users (id) on delete set null,
  deleted_at timestamptz, -- set when stopped
  foreign key (recipe_id, household_id) references public.recipes (id, household_id)
    on delete cascade deferrable initially immediate
);
create index shares_household_id_idx on public.shares (household_id);
create index shares_recipe_id_idx on public.shares (recipe_id);

create trigger shares_stamp before insert or update on public.shares
for each row execute function public.stamp_row();

-- Read by the household; deleted only by the 30-day purge; written only by
-- the functions below.
grant select, delete on public.shares to authenticated;
alter table public.shares enable row level security;

-- Mirrored by powersync/sync-config.yaml (household_shares). Change both together.
create policy shares_select on public.shares
for select to authenticated
using (household_id = (select public.auth_household_id()));

create policy shares_purge on public.shares
for delete to authenticated
using (
  household_id = (select public.auth_household_id())
  and (select public.auth_household_role()) in ('admin', 'member')
  and (
    (deleted_at is not null and deleted_at < now() - interval '30 days')
    or exists (select 1 from public.recipes r where r.id = recipe_id and r.deleted_at < now() - interval '30 days')
  )
);

-- Any member, viewers too (SPEC §2): the recipe must be live and theirs.
create function public.create_share(share_id uuid, recipe uuid, snap jsonb)
returns table (id uuid, token text)
language plpgsql security definer set search_path = '' as $$
#variable_conflict use_column
declare
  home uuid := public.auth_household_id();
  code text;
begin
  if home is null or not exists (
       select 1 from public.recipes r where r.id = recipe and r.household_id = home and r.deleted_at is null) then
    perform public.household_refuse('forbidden');
  end if;
  code := translate(rtrim(encode(decode(
    replace(gen_random_uuid()::text || gen_random_uuid()::text, '-', ''), 'hex'), 'base64'), '='), '+/', '-_');
  insert into public.shares (id, household_id, recipe_id, token_hash, snapshot)
  values (share_id, home, recipe, sha256(convert_to(code, 'UTF8')), snap);
  return query select share_id, code;
end;
$$;

create function public.stop_shares(recipe uuid) returns int
language plpgsql security definer set search_path = '' as $$
declare
  stopped int;
begin
  -- coalesce: with no claims the role is null, and "null not in (…)" is not true.
  if coalesce(public.auth_household_role()::text, '') not in ('admin', 'member') or not exists (
       select 1 from public.recipes r where r.id = recipe and r.household_id = public.auth_household_id()) then
    perform public.household_refuse('forbidden');
  end if;
  update public.shares s set deleted_at = now()
  where s.recipe_id = recipe and s.household_id = public.auth_household_id() and s.deleted_at is null;
  get diagnostics stopped = row_count;
  return stopped;
end;
$$;

-- Callable with no claims at all: returns one snapshot by its code, and
-- nothing about anything else (NFR-2).
create function public.read_share(code text)
returns table (status text, snapshot jsonb, share_id uuid, household_id uuid)
language plpgsql stable security definer set search_path = '' as $$
#variable_conflict use_column
declare
  s public.shares;
begin
  select * into s from public.shares sh where sh.token_hash = sha256(convert_to(code, 'UTF8'));
  if not found then return query select 'unknown'::text, null::jsonb, null::uuid, null::uuid; return; end if;
  if s.deleted_at is not null then return query select 'stopped'::text, null::jsonb, null::uuid, null::uuid; return; end if;
  if exists (select 1 from public.recipes r where r.id = s.recipe_id and r.deleted_at is not null)
     or exists (select 1 from public.households h where h.id = s.household_id and h.deleted_at is not null) then
    return query select 'trashed'::text, null::jsonb, null::uuid, null::uuid; return;
  end if;
  return query select 'ok'::text, s.snapshot, s.id, s.household_id;
end;
$$;

-- The caller's own household gets an independent copy (FR-27).
create function public.save_share(code text)
returns table (recipe_id uuid, photo_id uuid, source_household uuid, share_id uuid)
language plpgsql security definer set search_path = '' as $$
#variable_conflict use_column
declare
  home uuid := public.auth_household_id();
  found_share record;
  snap jsonb;
  new_recipe uuid := gen_random_uuid();
  new_photo uuid := null;

  end if;

  if found_share.status <> 'ok' then perform public.household_refuse('share_unavailable'); end if;
  if found_share.household_id = home then perform public.household_refuse('own_household'); end if;
  snap := found_share.snapshot;

  insert into public.recipes (id, household_id, title, servings, prep_minutes, cook_minutes,
                              ingredients, steps, tags, notes, source_url, source_author, source_text)
  values (
    new_recipe, home, snap ->> 'title',
    (snap ->> 'servings')::int, (snap ->> 'prep_minutes')::int, (snap ->> 'cook_minutes')::int,
    coalesce((select jsonb_agg(item || jsonb_build_object('id', gen_random_uuid()))
              from jsonb_array_elements(snap -> 'ingredients') item), '[]'::jsonb),

              from jsonb_array_elements(snap -> 'steps') item), '[]'::jsonb),
    array(select jsonb_array_elements_text(snap -> 'tags')),
    coalesce(snap ->> 'notes', ''),
    snap ->> 'source_url', snap ->> 'source_author',
    'Shared by the ' || (snap ->> 'household_name')
  );

    new_photo := gen_random_uuid();
    insert into public.photos (id, household_id, kind, recipe_id, media_type, bytes, width, height, uploaded_at)

  end if;

  return query select new_recipe, new_photo, found_share.household_id, found_share.share_id;
end;
```

```ts
import { randomUUID } from 'node:crypto';
import { buildShareSnapshot, shareSnapshotSchema, type ShareSnapshot } from '@recipe-app/domain';
import type { AsUser, UserTx } from '../db/asUser';
import type { PhotoStore } from '../photos/store';

export type ShareRefusalKey = 'forbidden' | 'share_unavailable' | 'own_household' | 'not_found';
export class ShareRefusal extends Error {
  constructor(readonly key: ShareRefusalKey) {
    super(key);
    this.name = 'ShareRefusal';
  }
}

export type SharingService = {
  create(token: string, recipeId: string): Promise<{ code: string }>;
  stop(token: string, recipeId: string): Promise<number>;
  read(code: string): Promise<{ status: string; snapshot: ShareSnapshot | null }>;
  photo(code: string): Promise<Uint8Array | null>;
  save(token: string, code: string): Promise<{ recipe_id: string }>;
};

type Anonymous = <T>(fn: (tx: UserTx) => Promise<T>) => Promise<T>;
const KEYS: readonly string[] = ['forbidden', 'share_unavailable', 'own_household'];

/** FR-26, FR-27 (ADR-0016). Every statement runs as the user, or as an anonymous caller for reads. */
export function createSharingService(deps: {
  asUser: AsUser;
  asAnonymous: Anonymous;
  store: Pick<PhotoStore, 'copy' | 'read'>;
  now?: () => Date;
}): SharingService {
  const now = deps.now ?? (() => new Date());

  async function refusals<T>(work: () => Promise<T>): Promise<T> {
    try {
      return await work();
    } catch (error) {
      const { code, message } = error as { code?: unknown; message?: unknown };
      if (code === 'P0001' && typeof message === 'string' && KEYS.includes(message)) {
        throw new ShareRefusal(message as ShareRefusalKey);
      }
      throw error;
    }
  }

  async function read(code: string) {
    const [row] = await deps.asAnonymous((tx) => tx<{ status: string; snapshot: unknown; share_id: string | null; household_id: string | null }[]>`
      select status, snapshot, share_id, household_id from public.read_share(${code})`);
    const parsed = row?.status === 'ok' ? shareSnapshotSchema.safeParse(row.snapshot) : null;
    return {
      status: parsed && !parsed.success ? 'unknown' : (row?.status ?? 'unknown'),
      snapshot: parsed?.success ? parsed.data : null,
      shareId: row?.share_id ?? null,
      householdId: row?.household_id ?? null,
    };
  }

  return {
    create: (token, recipeId) =>
      refusals(() =>
        deps.asUser(token, async (tx) => {
          const [recipe] = await tx<Record<string, unknown>[]>`
            select r.title, r.servings, r.prep_minutes, r.cook_minutes, r.ingredients, r.steps, r.tags,
                   r.notes, r.source_url, r.source_author, r.household_id, h.name as household_name,
                   p.id as photo_id, p.bytes as photo_bytes, p.width as photo_width, p.height as photo_height
            from public.recipes r
            join public.households h on h.id = r.household_id
            left join public.photos p on p.id = r.photo_id and p.uploaded_at is not null and p.deleted_at is null
            where r.id = ${recipeId} and r.deleted_at is null`;
          if (!recipe) throw new ShareRefusal('not_found');
          const shareId = randomUUID();
          const copied =
            typeof recipe.photo_id === 'string'
              ? await deps.store.copy(String(recipe.household_id), recipe.photo_id, String(recipe.household_id), shareId)
              : false;
          const snapshot = shareSnapshotSchema.parse(
            buildShareSnapshot(
              {
                title: String(recipe.title),
                servings: (recipe.servings as number | null) ?? null,
                prep_minutes: (recipe.prep_minutes as number | null) ?? null,
                cook_minutes: (recipe.cook_minutes as number | null) ?? null,
                ingredients: (recipe.ingredients as never) ?? [],
                steps: (recipe.steps as never) ?? [],
                tags: (recipe.tags as string[] | null) ?? [],
                notes: (recipe.notes as string | null) ?? '',
                source_url: (recipe.source_url as string | null) ?? null,

        }
```

```ts
/** FR-26, FR-27 (spec §5). Reads need no token; everything else does. */
export function registerSharingRoutes(app: Hono, deps: { sharing: SharingService }): void {
  const { sharing } = deps;

  async function signedIn(c: Context, action: (token: string) => Promise<Response>) {
    const token = bearer(c.req.header('Authorization'));
    if (!token) return c.json({ error: 'unauthorized' }, 401);
    try {
      return await action(token);
    } catch (error) {
      if (!(error instanceof ShareRefusal)) throw error;
      return c.json({ error: error.key }, STATUS[error.key]);
    }
  }

  async function recipeId(c: Context): Promise<string | null> {
    const body = (await c.req.json().catch(() => null)) as { recipe_id?: unknown } | null;
    return typeof body?.recipe_id === 'string' && isGuid(body.recipe_id) ? body.recipe_id : null;
  }

  app.post('/api/shares', (c) =>
    signedIn(c, async (token) => {
      const id = await recipeId(c);
      if (!id) return c.json({ error: 'invalid_body' }, 400);
      return c.json(await sharing.create(token, id), 201);
    }),
  );

  app.post('/api/shares/stop', (c) =>
    signedIn(c, async (token) => {
      const id = await recipeId(c);
      if (!id) return c.json({ error: 'invalid_body' }, 400);
      return c.json({ stopped: await sharing.stop(token, id) });
    }),
  );

  app.get('/api/shares/:code', async (c) => {
    c.header('Cache-Control', 'no-store');
    if (!CODE.test(c.req.param('code'))) return c.json({ status: 'unknown' }, 404);
    const { status, snapshot } = await sharing.read(c.req.param('code'));
    if (status !== 'ok' || !snapshot) return c.json({ status }, 404);
    return c.json({ snapshot, has_photo: snapshot.photo !== null });
  });

  app.get('/api/shares/:code/photo', async (c) => {
    c.header('Cache-Control', 'no-store');
    if (!CODE.test(c.req.param('code'))) return c.json({ error: 'not_found' }, 404);
    const bytes = await sharing.photo(c.req.param('code'));
    if (!bytes) return c.json({ error: 'not_found' }, 404);
    return c.body(bytes as Uint8Array<ArrayBuffer>, 200, { 'Content-Type': 'image/jpeg' });
  });

  app.post('/api/shares/:code/save', (c) =>
    signedIn(c, async (token) => {
      if (!CODE.test(c.req.param('code'))) return c.json({ error: 'share_unavailable' }, 404);
      return c.json(await sharing.save(token, c.req.param('code')), 201);
    }),
  );
```

```ts
import { pdfSafeText, sourceLine, timesLine, type ShareableRecipe } from '@recipe-app/domain';
import { jsPDF } from 'jspdf';

type PdfRecipe = Omit<ShareableRecipe, 'tags'>;
export type PdfPhoto = { dataUrl: string; width: number; height: number };

// Letter, in points.
const PAGE = { width: 612, height: 792, margin: 54 };
const BOTTOM = PAGE.height - PAGE.margin - 18;
const TWO_COLUMNS_ABOVE = 12;

/** FR-26: the recipe as a tidy PDF, made on the phone. */
export function buildRecipePdf(recipe: PdfRecipe, photo: PdfPhoto | null): jsPDF {
  const doc = new jsPDF({ unit: 'pt', format: 'letter', compress: false });
  const width = PAGE.width - PAGE.margin * 2;
  let y = PAGE.margin;

  const ensure = (height: number) => {
    if (y + height > BOTTOM) {
      doc.addPage();
      y = PAGE.margin;
    }
  };
  const write = (text: string, size: number, style: 'normal' | 'bold' = 'normal', indent = 0, gap = 4) => {
    doc.setFont('helvetica', style).setFontSize(size);
    for (const part of doc.splitTextToSize(pdfSafeText(text), width - indent) as string[]) {
      ensure(size * 1.25);
      doc.text(part, PAGE.margin + indent, y + size);
      y += size * 1.25;
    }
    y += gap;
  };

  write(recipe.title, 22, 'bold', 0, 6);
  if (photo) {
    const scale = Math.min(width / photo.width, 220 / photo.height, 1);
    const w = photo.width * scale;
    const h = photo.height * scale;
    ensure(h + 8);
    doc.addImage(photo.dataUrl, 'JPEG', PAGE.margin, y, w, h);
    y += h + 8;
  }
  const times = timesLine(recipe);
  if (times) write(times, 11, 'normal', 0, 10);

  if (recipe.ingredients.length > 0) {
    write('Ingredients', 14, 'bold');
    const lines = recipe.ingredients.map((item) => (item.heading ? item.raw : `• ${item.raw}`));
    const twoColumns = recipe.ingredients.filter((item) => !item.heading).length > TWO_COLUMNS_ABOVE;
    const rowHeight = 11 * 1.35;
    const half = Math.ceil(lines.length / 2);
    if (twoColumns && y + half * rowHeight <= BOTTOM) {
      doc.setFont('helvetica', 'normal').setFontSize(11);
      const column = (width - 18) / 2;
      lines.forEach((line, index) => {
        const left = index < half;
        const row = left ? index : index - half;
        const text = (doc.splitTextToSize(pdfSafeText(line), column) as string[])[0] ?? '';
        doc.text(text, PAGE.margin + (left ? 0 : column + 18), y + 11 + row * rowHeight);
      });
      y += half * rowHeight + 10;
    } else {
      for (const line of lines) write(line, 11, 'normal', 0, 1);
      y += 8;
    }
  }

  if (recipe.steps.length > 0) {
    write('Steps', 14, 'bold');
    recipe.steps.forEach((step, index) => write(`${index + 1}. ${step.text}`, 11, 'normal', 0, 6));
    y += 4;
  }
  if (recipe.notes.trim()) {
    write('Notes', 14, 'bold');
    write(recipe.notes.trim(), 11);
  }
  const source = sourceLine(recipe);
  if (source) write(source, 10);

  const pages = doc.getNumberOfPages();
  for (let page = 1; page <= pages; page++) {
    doc.setPage(page);
    doc.setFont('helvetica', 'normal').setFontSize(9).setTextColor(120);
    doc.text('Shared from Recipes', PAGE.width / 2, PAGE.height - PAGE.margin / 2, { align: 'center' });
    doc.setTextColor(0);
  }
  return doc;
}

/** "<Title>.pdf", without characters a file name can't have (Review Focus 2). */
export function pdfFileName(title: string): string {
  const clean = title
    .replace(/[/\\]/g, '-')
    .replace(/\s*:\s*/g, ' - ')
    .replace(/[<>"|?*\u0000-\u001f]/g, '')
    .replace(/\s+/g, ' ')
    .trim();
  return `${clean || 'Recipe'}.pdf`;
}

export function recipePdfFile(recipe: PdfRecipe, photo: PdfPhoto | null): File {
  const blob = buildRecipePdf(recipe, photo).output('blob');
  return new File([blob], pdfFileName(recipe.title), { type: 'application/pdf' });
}
```

```ts
/** The share sheet with text, or the clipboard where there is none. */
export async function shareOrCopy(content: { title: string; text: string }): Promise<'shared' | 'copied' | 'cancelled'> {
  const nav = globalThis.navigator as Navigator | undefined;
  if (nav?.share) {
    try {
      await nav.share(content);
      return 'shared';
    } catch {
      return 'cancelled';
    }
  }
  try {
    await nav?.clipboard?.writeText(content.text);
    return 'copied';
  } catch {
    return 'cancelled';
  }
}

/** The share sheet with a file where it can take files; otherwise a download. */
export async function shareFile(file: File, title: string): Promise<'shared' | 'downloaded' | 'cancelled'> {
  const nav = globalThis.navigator as Navigator | undefined;
  if (nav?.canShare?.({ files: [file] })) {
    try {
      await nav.share({ files: [file], title });
      return 'shared';
    } catch {
      return 'cancelled';
    }
  }
  const url = URL.createObjectURL(file);
  const link = document.createElement('a');
  link.href = url;
  link.download = file.name;
  document.body.append(link);
  link.click();
  link.remove();
  setTimeout(() => URL.revokeObjectURL(url), 10_000);
  return 'downloaded';
}
```

```ts
    });
    const json = (await response.json().catch(() => null)) as { error?: string } | null;
    if (!response.ok) return { ok: false, message: SHARE_MESSAGES[json?.error ?? ''] ?? 'Something went wrong. Try again.' };
    return { ok: true, value: json as T };
  } catch {
    return { ok: false, message: OFFLINE };
  }
}

export const createShare = (recipeId: string, deps: ApiDeps) => call<{ code: string }>(deps, '/shares', { recipe_id: recipeId });
export const stopShares = (recipeId: string, deps: ApiDeps) => call<{ stopped: number }>(deps, '/shares/stop', { recipe_id: recipeId });
export const saveShare = (code: string, deps: ApiDeps) => call<{ recipe_id: string }>(deps, `/shares/${code}/save`);

/** No token: a shared page is readable by anyone with the link. */
export async function readShare(
  code: string,
  fetchImpl: typeof fetch,
  apiUrl: string,
): Promise<{ ok: true; snapshot: ShareSnapshot; hasPhoto: boolean } | { ok: false; status: string }> {
  try {
    const response = await fetchImpl(`${apiUrl}/shares/${encodeURIComponent(code)}`, { cache: 'no-store', headers: {} });
    const json = (await response.json().catch(() => null)) as { snapshot?: ShareSnapshot; has_photo?: boolean; status?: string } | null;
    if (response.ok && json?.snapshot) return { ok: true, snapshot: json.snapshot, hasPhoto: Boolean(json.has_photo) };
    return { ok: false, status: json?.status ?? 'unknown' };
  } catch {
    return { ok: false, status: 'offline' };
  }
}
```

```ts
// A shared recipe someone chose to save while signed out (spec §6), and the
// one-time "Saved to your recipes" message.
const PENDING = 'recipes.pendingShare';
const FLASH = 'recipes.savedFlash';
const CODE = /^[A-Za-z0-9_-]{43}$/;

type Pending = { code: string; title: string };

export function setPendingShare(pending: Pending): void {
  globalThis.sessionStorage?.setItem(PENDING, JSON.stringify(pending));
}

export function peekPendingShare(): Pending | null {
  try {
    const value = JSON.parse(globalThis.sessionStorage?.getItem(PENDING) ?? 'null') as Partial<Pending> | null;
    return value && typeof value.code === 'string' && CODE.test(value.code) && typeof value.title === 'string'
      ? { code: value.code, title: value.title }
      : null;
  } catch {
    return null;
  }
}

export function takePendingShare(): Pending | null {
  const value = peekPendingShare();
  globalThis.sessionStorage?.removeItem(PENDING);
  return value;
}

export function setSavedFlash(): void {
  globalThis.sessionStorage?.setItem(FLASH, '1');
}

export function takeSavedFlash(): boolean {
  const value = globalThis.sessionStorage?.getItem(FLASH) === '1';
  globalThis.sessionStorage?.removeItem(FLASH);
  return value;
}
```

```markdown
## Context

Sharing out (FR-26, FR-27) sends recipes to people outside the household, some without an account. A link must show the recipe as it was when shared and nothing else of the household (NFR-2). A recipient who saves it needs a copy in their own household, which their RLS cannot read from.

## Decision

- **A `shares` row per link** holds a validated snapshot of the recipe and a copy of its dish photo file (`photos/<household>/<share id>.jpg`). The link code is 32 random bytes; only its sha256 is stored. Links last until stopped. A recipe in the Trash pauses its links.
- **Definer functions:** `create_share`, `stop_shares`, `read_share` and `save_share`, with `search_path = ''`, check the caller themselves. `read_share` returns one snapshot by its code hash, and only while the share and its recipe are live.
- **`asAnonymous`:** the API serves signed-out visitors through `asAnonymous`, the `authenticated` role with empty claims. Every RLS policy denies it; it may call only `read_share`.
- **Saving a copy:** `save_share` makes a new recipe in the caller's household (admins and members), with new ids and the source "Shared by the <household>".
- **Text and PDF are made on the phone.** The PDF uses jsPDF (MIT), loaded on first use, with its built-in Helvetica and a fallback map for fractions the font lacks.
- **The 30-day purge** deletes stopped shares and their photo copies through RLS (`shares_purge`).

## Alternatives considered

- **Serving the live recipe:** later edits and deletions would leak (NFR-2).
- **A public role, or a signed URL service:** more moving parts than one narrow function.
- **A server-made PDF:** needs a connection and a headless browser.
- **An embedded Unicode font:** larger PDFs and an extra asset, for six glyphs.

## Consequences

- **CLAUDE.md rule 1** lists these functions and `asAnonymous`. No other code may use empty claims.
- **A link outlives edits:** to send a newer version, share again.
- **The app gains jsPDF** (about 300 KB), loaded only when a PDF is made.
```

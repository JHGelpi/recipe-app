# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-12

## Context
Design decisions were made in conversation and will be revisited by people (and AI coding agents) without that context.

## Decision
Record significant architecture decisions as ADRs in `docs/adr/`, using `template.md`. `ARCHITECTURE.md` describes the current state; ADRs explain why.

## Consequences
Every new dependency, data-model convention, or cross-cutting pattern gets an ADR in the same PR that introduces it.
